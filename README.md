# Earnings Verifier

English | [简体中文](README.zh-CN.md)

Extracts core financial figures from periodic reports of US, China A-share and Hong Kong listed companies (revenue, net income attributable to the parent, basic EPS, gross profit, operating cash flow; banks and insurers have their own templates). Every figure comes with its page and a verbatim quote, and is then checked by code; suspicious figures are flagged in red.

- Live site: https://earnings-verifier.streamlit.app/
- Keep-alive: the GitHub Actions workflow [`keep-alive`](.github/workflows/keep-alive.yml) opens the site every 6 hours. If Streamlit's sleep page appears, it clicks the wake-up button and only succeeds once the app shows the product name; a failed run turns red and GitHub sends an email. The address is read from the repository variable `APP_URL`, so a new address only needs that variable changed.
- The examples and the Verify page need no API key; single analysis and batch compare use your own key (DeepSeek by default; several providers supported).

## What it does, and what it does not

1. **Fetch and locate**: downloads the filing from SEC EDGAR, cninfo or HKEXnews and finds the statement pages.
2. **Copy**: the model only copies the number, unit, page and full source line from the filing; it does no conversion.
3. **Code checks**:
   - C1 the quote is on the page;
   - C2 the number appears verbatim on the page;
   - C3 unit and currency can be parsed;
   - C4 comparison with SEC XBRL / Eastmoney (US and A-shares only);
   - S1–S5 consistency checks.

   Figures that fail are flagged in red with a one-sentence reason.
4. **Top of the result page**: the verification verdict and the key-change cards (revenue, net income attributable, gross margin, EPS) are generated by code; year-on-year changes and ratios are also computed by code. Prior-year figures are copied by a separate model call and also go through C1–C3. Highlights are written by the model from the result table (in Chinese and English); code checks the source of every number and hides points that fail; the wording has not been evaluated.

The checks can only confirm that a number is in the filing, in the right unit and consistent with other numbers. **They cannot confirm that it is the metric you wanted.** Not flagged does not mean correct.

## Evaluation (all numbers in [docs/eval_results.md](docs/eval_results.md))

Three tiers were compared on DeepSeek: simple direct question / expert direct question / pipeline, scored on a 60-filing evaluation set and a 60-filing holdout set.

- **The expert direct question had the highest strict accuracy**: 97.1% on eval1 (all three markets), versus 92.6% for the pipeline.
- The pipeline differs in that every number has a page and a quote, and suspicious numbers are flagged:
  - on the US + A-share holdout, the pipeline's strict accuracy was 96.1%, 4.9% of rows were flagged for review, and 0 of 205 rows were wrong without being flagged;
  - flag recall is clearly lower for Hong Kong: in the frozen run, 3 of 10 errors were not flagged, because Hong Kong has no reliable structured data to compare against.
- Limitations:
  - mainly DeepSeek; Fable has only a 9-filing sample;
  - the input is parsed text, not the PDF;
  - the Hong Kong holdout was not scored;
  - the revisions were made after seeing results; the freeze and revision process is in [docs/eval_design.md](docs/eval_design.md) §10.

## Universal prompt

[`prompts/`](prompts/) holds a universal prompt in Chinese and English for use with any AI (GPT, Claude, DeepSeek, Doubao, etc.).
- Usage: upload the filing, paste the prompt, then paste the AI's whole reply into the site's Verify page to check every number by code.
- It asks for the PDF page index and the full source line for every number, `not_disclosed` (no estimates) where the filing has no such line, and JSON plus a readable table.

Evaluation status:
- It is adapted from the question of the "expert direct question + verification layer" tier (R3) in the evaluation. R3 scored 97.1% strict accuracy on the DeepSeek holdout (205 US + A-share rows, parsed text as input; see [docs/eval_results.md](docs/eval_results.md) §3).
- The universal version changes the output format and has not been evaluated on its own; other models have not been evaluated.

## Run locally

```bash
python3.9 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/streamlit run app.py
```

Extract one filing from the command line (uses the key in `.env`; template in `.env.example`):

```bash
.venv/bin/python -m earnings_agent extract --market hk --code 00700 --period 2026H1
```
